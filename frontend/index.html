⭐ K-Means Clustering

Cocok untuk
  • Segmentasi marketing & campaign targeting
  • Data dengan cluster berbentuk bulat/globular
  • Butuh interpretasi bisnis yang mudah dipahami
  • Dataset besar dengan kebutuhan kecepatan tinggi
Tidak cocok untuk
  • Data dengan banyak outlier ekstrem
  • Cluster dengan bentuk tidak beraturan

🔍 DBSCAN

Cocok untuk
  • Deteksi fraud & anomali transaksi
  • Cluster dengan bentuk bebas / tidak beraturan
  • Jumlah cluster tidak diketahui sebelumnya
  • Perlu isolasi outlier secara otomatis
Tidak cocok untuk
  • Kepadatan cluster sangat berbeda-beda
  • Dataset sangat high-dimensional tanpa reduksi
